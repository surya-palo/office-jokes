## The joke

> My boss said AI could never replace me — then asked me to train my replacement.

## How it works

`main.py` (Python 3.13, standard library only) writes the one-line joke above to `/output/entry.txt`, creating `/output` if needed. The joke is a constant in the source, so the output is deterministic: every run produces byte-identical output.

Run it with:

```sh
python3 main.py
```
